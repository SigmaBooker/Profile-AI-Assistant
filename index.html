LinkedIn AI Assistant

Finance & Accounting · Freelance Engine

⚙️ One-time setup required

Before connecting LinkedIn, configure your 3 credentials in the HTML file. Takes ~5 minutes.

1

Create a LinkedIn Developer App

Go to linkedin.com/developers/apps/new, create an app, go to Auth tab. Copy your Client ID.

2

Add OAuth redirect URI

In the Auth tab → Authorized redirect URLs, add exactly:
https://YOUR_GITHUB_USERNAME.github.io/linkedin-ai-assistant/callback.html
Also enable these scopes: openid, profile, email

3

Edit the config block in index.html

Open this file and update the 3 values at the top:

const LI_CLIENT_ID = ''YOUR_CLIENT_ID'';
const LI_REDIRECT_URI = ''https://you.github.io/linkedin-ai-assistant/callback.html'';
const CLAUDE_API_KEY = ''sk-ant-...'';
4

Deploy both files to GitHub Pages

Push index.html and callback.html to your GitHub repo. Enable GitHub Pages from Settings → Pages → Branch: main. Done.
